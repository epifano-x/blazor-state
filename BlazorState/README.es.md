
# Gestión de Estado en Blazor

## 🛠 Descripción del Proyecto
Este proyecto demuestra la **gestión de estado en Blazor**, utilizando un enfoque global para compartir datos entre componentes sin necesidad de pasar parámetros directamente.

## 🚀 Comenzando
1. Clonar este repositorio:
   ```sh
   git clone https://github.com/yourusername/blazor-state.git
   ```
2. Navegar al directorio del proyecto:
   ```sh
   cd blazor-state
   ```
3. Ejecutar la aplicación:
   ```sh
   dotnet run
   ```
