## 🛠 Descrição do Projeto
Este projeto demonstra o **gerenciamento de estado no Blazor**, utilizando uma abordagem global para compartilhar dados entre componentes sem a necessidade de passar parâmetros diretamente.

## 🚀 Começando
1. Clone este repositório:
   ```sh
   git clone https://github.com/yourusername/blazor-state.git
   ```
2. Navegue até o diretório do projeto:
   ```sh
   cd blazor-state
   ```
3. Execute a aplicação:
   ```sh
   dotnet run
   ```
